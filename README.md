# ChatGPT Operating Framework

An open-source, evidence-driven framework for configuring and improving how ChatGPT supports real work — with less dependence on expert prompting.

> **Stage:** Initial specification and reusable instruction template. Not yet a software release, account-configuration utility, or proven performance improvement.

## Why this exists
People should be able to describe outcomes in ordinary language. Their AI working environment should preserve objectives, select appropriate methods, use the tools actually available, complete authorized work and verify results.

This project formalizes an existing ChatGPT operating-environment workflow without expanding its intended use case to an unrelated AI agent platform.

## Start here
1. Read the [project charter](docs/CHARTER.md) for mission, scope and safeguards.
2. Review the [portable personal instructions](templates/CUSTOM_INSTRUCTIONS.md) and apply them manually through supported ChatGPT settings if appropriate.
3. Use the [evaluation protocol](docs/EVALUATION.md) to distinguish configured preferences from demonstrated improvements.
4. See the [roadmap](docs/ROADMAP.md) for what is implemented, what is proposed and what remains unverified.

## Core areas
Configuration and permissions · intent and constraints · project continuity · tool and skill use · verified delivery · reproducible evaluations · reversible improvements.

## What this **does not** do
It does not unlock plan features, modify model weights, guarantee the best possible model outputs, or change unsupported account settings automatically. It is not affiliated with or endorsed by OpenAI.

## Privacy and safety
The repository contains generalized reusable material, **not** personal settings exports, private chats, customer data, credentials or personal project records. Publishing these requires deliberate review and authorization.

## Project status
The originating private implementation (21 October 2026) recorded saved instructions, a verified-delivery skill and focused smoke tests. No controlled study has yet demonstrated a causal improvement in output quality. This public repository is the beginning of a reproducible implementation, not evidence of one.

Contributions and licensing policy will be finalized before inviting substantial external contributions.
